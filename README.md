# 🍲 BonneApptit - Global Recipes Explorer

**BonneApptit** is a comprehensive culinary application that brings world cuisines to your fingertips. From Italian pasta to Oriental delights, the app provides a rich database of recipes tailored for all dietary preferences, including dedicated sections for **Vegetarian** and **Meat-based** dishes.

---

## 🚀 Key Features

- **Global Kitchens Explorer:** Access recipes from Italian, American, Oriental, and many other international cuisines.
- **Dietary Categories:** Specialized filters for Vegetarian, Vegan, and Meat lovers.
- **Smart Search:** Find your favorite recipes instantly using the integrated Search View.
- **Offline Access:** Save and browse your favorite recipes without an internet connection, powered by **Room DB**.
- **Dark Mode Support:** A fully adaptive UI with **DarkView** for a comfortable cooking experience at any time.

---

## 🛠 Tech Stack & Tools

- **Language:** [Kotlin](https://kotlinlang.org/) - Built with modern Android standards.
- **Architecture:** **MVVM** (Model-View-ViewModel) following Clean Architecture principles.
- **Networking:** [Retrofit](https://square.github.io/retrofit/) & OkHttp for fetching restful API recipe data.
- **Asynchronous Work:** [Coroutines](https://kotlinlang.org/docs/coroutines-overview.html) for smooth, non-blocking operations.
- **Local Persistence:** [Room Database](https://developer.android.com/training/data-storage/room) for caching and offline storage.
- **UI & Design:** [Material Design](https://material.io/) and **Android Jetpack** components for a polished, modern look.

---

## 🏗 Architectural Highlights

As a **Senior Developer**, I designed this app with a focus on:
- **Scalability:** Easily add new cuisines or dietary filters without breaking existing logic.
- **Data Integrity:** Seamless synchronization between the remote API and the local Room database.
- **UX Excellence:** Implementing a smooth "Search-as-you-type" experience and clear categorization.
